# Contributing

FinancialResearch accepts public feedback, not unsolicited code changes.

Ordinary users may submit Issues, Discussions, bug reports, design proposals,
research observations, and modification suggestions.

Unsolicited code changes and pull requests are not accepted. Source changes to
the upstream repository are accepted only from collaborators explicitly invited
and authorized by the owner.

Collaborator access does not grant external redistribution, commercialization,
sublicensing, or derivative-publication rights. Contributors must own or have
permission to submit all contributed material.

Future contributor or relicensing arrangements remain subject to separate
written agreement.
